# Workout Tracker Mobile for GitHub Pages

This is the GitHub Pages version of the mobile workout tracker.

## Files
- `index.html` — main app file for GitHub Pages

## Publish on GitHub Pages
1. Create a new public GitHub repository.
2. Upload `index.html` to the root of the repository.
3. Go to **Settings -> Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/root` folder, then save.
6. GitHub will publish the site at your Pages URL.

## What this version does
- Mobile-friendly workout interface
- Pre-filled exercise names by day
- Workout timer
- Stretch guidance by day
- Email draft button using `mailto:`
- Text draft button using `sms:`

## Notes
- Email drafts are generally more reliable than SMS drafts across phones.
- Since this is a static app, it does not require a backend.
- You can add the published URL to your phone home screen.
